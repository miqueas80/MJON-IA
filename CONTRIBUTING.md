# Contribuir a MJON IA

En la etapa privada se trabaja directamente en `main`, con cambios pequeños y pruebas previas. Los cambios problemáticos se revierten con `git revert`, conservando el historial.

Cuando el repositorio sea público podrán proponerse cambios e issues con revisión. Cualquier contribución de datos debe incluir procedencia, derechos de uso, licencia y protección de privacidad. Nunca se deben subir secretos, datos personales ajenos ni archivos sin permiso.

Pruebas: `python -m unittest discover -s tests -v`.
